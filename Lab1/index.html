01

История создания

Всё началось в 1979 году в исследовательском центре Bell Labs, где молодой датский программист Бьёрн Страуструп (Bjarne Stroustrup) работал над распределённой системой и остро нуждался в языке, который был бы одновременно быстрым, как C, и выразительным, как Simula.

Первая версия носила имя C with Classes — по сути, это был препроцессор над классическим C, добавлявший классы, наследование и контроль доступа. Уже тогда появились знакомые нам class, public и private.

В 1983 году язык получил своё нынешнее имя. Название C++ — это игра операторов: ++ в C означает инкремент, то есть «C, но на шаг дальше». Именно тогда к классам добавились виртуальные функции, перегрузка операторов, ссылки и const.

В 1985 году вышла первая книга Страуструпа — The C++ Programming Language, ставшая де-факто стандартом языка до появления официальной спецификации. А в 1998 году усилиями комитета ISO был ратифицирован первый настоящий стандарт — C++98.

«C++ — это язык, который не мешает вам выстрелить себе в ногу, но если вы всё-таки выстрелите, то оторвёт всю ногу целиком».

— Бьёрн Страуструп

Этапы стандартизации

  1. 1979–1983 — «C with Classes»: классы, наследование, препроцессор cfront.
  2. 1985–1989 — C++ 1.0 и 2.0: виртуальные функции, множественное наследование, шаблоны.
  3. 1998 — ISO C++98: STL официально становится частью стандарта.
  4. 2011 — C++11: auto, лямбды, rvalue-ссылки, nullptr, многопоточность.
  5. 2017 — C++17: structured bindings, std::optional, std::filesystem, fold-выражения.
  6. 2020 — C++20: концепты, диапазоны (ranges), корутины, модули.
  7. 2023 — C++23: std::expected, std::print, плоские контейнеры.

Сегодня C++ — это язык с 40+ годами непрерывной эволюции и обратной совместимостью практически на всём её протяжении. Подробнее — на официальном сайте Бьёрна Страуструпа и в cppreference. Дальше — краткий обзор языка.

02

Краткий обзор языка

C++ — это компилируемый, статически типизированный язык общего назначения, поддерживающий несколько парадигм одновременно: процедурное, объектно-ориентированное, обобщённое и функциональное программирование. Его девиз — «zero-cost abstractions»: вы не платите за то, чем не пользуетесь.

Ключевые характеристики

  • Производительность. Код компилируется в машинные инструкции без прослойки виртуальной машины.
  • Ручное управление памятью — и одновременно RAII и умные указатели.
  • Шаблоны — метапрограммирование, выполняемое во время компиляции.
  • Богатая стандартная библиотека: контейнеры, алгоритмы, потоки, файловая система.
  • Детерминированное разрушение объектов — никакого сборщика мусора.
  • Переносимость — от микроконтроллеров до суперкомпьютеров.

Области применения

  • Игровые движки — Unreal Engine, Unity (нативная часть), CryEngine.
  • Браузеры — Chrome (Blink), Firefox (Gecko), Safari (WebKit).
  • Операционные системы — ядро Windows, части Linux, macOS.
  • Финансовые системы — биржевые движки с микросекундными задержками.
  • Наука и HPC — симуляции, численные методы, ROOT в CERN.
  • Встраиваемые системы и робототехника — ROS 2, автопилоты, дроны.

Мини-глоссарий

RAII
Resource Acquisition Is Initialization — ресурс живёт ровно столько, сколько живёт объект.
Шаблон
Механизм обобщённого программирования: код параметризуется типами и значениями.
UB
Undefined Behaviour — неопределённое поведение; компилятор вправе сделать что угодно.
STL
Standard Template Library — контейнеры, итераторы и алгоритмы стандартной библиотеки.
Перегрузка
Возможность иметь несколько функций или операторов с одним именем, но разными параметрами.

Частые вопросы

C++ и C — это одно и то же?

Нет. C — подмножество C++ лишь исторически и не полностью. C++ добавляет классы, шаблоны, исключения, пространства имён, перегрузку и строгую типизацию. Многие программы на C компилируются как C++, но далеко не все.

Почему C++ считают сложным?

Из-за огромного пространства возможностей: ручное управление памятью, неопределённое поведение, множественное наследование, шаблонная метапрограммика. Но современный C++ (C++17/20/23) с auto, умными указателями и std::string_view пишется заметно проще, чем принято думать.

Нужно ли учить C перед C++?

Не обязательно, но полезно понимать, что такое указатели, стек и куча. Однако учить «C-стилю» в C++ не стоит: вместо malloc используется new и контейнеры, вместо char* — std::string.

Примеры кода

Ниже — четыре небольших примера, показывающих разные грани языка. Переключайте вкладки и копируйте код кнопкой в правом верхнем углу блока. Все примеры проверены на g++ -std=c++20. 

// hello.cpp — первая программа на C++
#include <iostream>
#include <string>

int main() {
    std::string name = "world";
    std::cout << "Hello, " << name << "!" << std::endl;
    return 0;
}
// Класс с инкапсуляцией и RAII-семантикой
#include <string>
#include <utility>

class Player {
public:
    explicit Player(std::string name, int hp)
        : name_{ std::move(name) }
        , hp_{ hp } {}

    void damage(int amount) noexcept {
        hp_ = (hp_ - amount < 0) ? 0 : hp_ - amount;
    }

    [[nodiscard]] bool alive() const noexcept {
        return hp_ > 0;
    }

    const std::string& name() const noexcept {
        return name_;
    }

private:
    std::string name_;
    int        hp_;
};
// Шаблоны и fold-выражения (C++17)
#include <cstddef>
#include <type_traits>

template <typename T, std::size_t N>
constexpr std::size_t array_size(const T (&)[N]) noexcept {
    return N;
}

template <typename... Ts>
auto sum(Ts... args) noexcept {
    return (args + ...);   // C++17: свёртка
}

int main() {
    int data[] = { 1, 2, 3, 4 };
    static_assert(array_size(data) == 4);
    return sum(1, 2, 3);   // 6
}
// Умные указатели: владение без утечек
#include <memory>
#include <vector>

struct Texture { std::string path; };

class Renderer {
public:
    void load(std::string file) {
        atlas_.push_back(
            std::make_shared<Texture>(Texture{ std::move(file) })
        );
    }

private:
    std::vector<std::shared_ptr<Texture>> atlas_;
};

int main() {
    auto widget = std::make_unique<Renderer>();
    widget->load("wall.png");
    return 0;   // память освобождается автоматически
}
